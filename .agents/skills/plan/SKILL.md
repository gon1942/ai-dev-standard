# Plan Adapter

규칙·입력·출력·게이트의 SSOT는 `docs/skill-contracts/standard-plan.md`다.
해당 계약과 `docs/development-workflow.md`를 읽고 그대로 수행한다.
사람 승인·수정 요청·보류는 `docs/skill-contracts/standard-human-decision.md`를 따른다.

공식 산출물은 `docs/product-specs/`와 `docs/exec-plans/active/`이며, Implement 전
`scripts/validate-plan.sh <계획>`을 통과해야 한다.
