# Project Constitution

> 이 프로젝트만의 장기 원칙·제약·승인된 결정을 기록한다.
> 공통 규칙은 `docs/coding-standards.md`·`docs/testing-policy.md`·
> `docs/development-workflow.md`를 따른다 — 여기에 복제하지 않는다.
> 이 문서의 변경은 별도 Product Spec과 사람 승인으로 진행한다.

- 상태: 초안
- 최종 승인: <사람>
- 최종 변경일: <날짜>

> 상태 값은 `초안` 또는 `확정`만 사용한다.
> `확정`은 사람이 검토·승인한 뒤에만 설정한다.

## 고위험 변경과 승인 경계

- 미확정: 사람 승인 없이 수정할 수 없는 영역 (예: 인증, 결제, DB 마이그레이션, 배포)

## 아키텍처 불변 조건

- 미확정: 현재 구조에서 바꾸지 않기로 한 것 — 사실 기술은 `ARCHITECTURE.md`를 따른다

## 규제·컴플라이언스 요건

- 미확정: 적용받는 규제·인증·감사 요건

## 인증·권한·외부 연동 정책

- 미확정: 프로젝트 고유의 인증·권한·외부 서비스 정책

## 데이터·프라이버시 정책

- 미확정: 수집·보관·삭제 정책과 개인정보 취급 경계

## 프로젝트별 필수 검증 수준

- 미확정: 브라우저 실측·통합·성능·보안 검증 중 이 프로젝트가 필수로 요구하는 것

## 안티골 — 기술적으로 가능해도 하지 않을 것

- 미확정: 기술적으로 성공해도 실패로 간주하는 것

## 미확정 결정·확정에 필요한 정보

- 항목 | 결정 필요 사항 | 확정에 필요한 정보 | 담당
- 없음 (모든 섹션 확정 시 이 표를 유지)
