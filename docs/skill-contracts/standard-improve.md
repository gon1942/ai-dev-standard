# Standard Improve Contract

## Entry conditions

- 작업 종료 뒤 반복 문제 또는 개선 근거가 있다.

## Required actions

- `scripts/new-improvement-candidate.sh`로 문제·근거·영향·출처 계획을 기록한다.
- 개선 후보를 사용자에게 제시하고 사람의 approve/reject 결정을 기다린다.

## Outputs

- 후보, 승인 또는 기각 기록

## Exit conditions

- 승인 전에는 공통 규칙·스킬·스크립트를 수정하지 않는다.
- 승인된 개선은 별도 Product Spec과 Exec Plan으로 다시 `standard-plan`부터 진행한다.
