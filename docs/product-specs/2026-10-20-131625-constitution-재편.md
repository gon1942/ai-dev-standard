# Product Spec: constitution-재편

- 상태: approved
- 유형: 수정
- 깊이: 일반
- 생성: 2026-10-20
- 사용자 요청: Constitution 재편 승인 (리뷰 보완 2건 — 엄격한 스킵 판정·회귀 3케이스 포함)

## 문제·목표

- 문제: 현 헌법은 공통 규칙을 복제해 SSOT 원칙과 충돌하고, 본연 역할인 프로젝트 고유 결정란은 "미확정" 한 줄뿐이며 질문 도구와 연결돼 있지 않다.
- 목표: 공통 규칙은 참조만 남기고, 사람이 확정할 프로젝트 고유 결정(고위험 경계·아키텍처 불변·규제·인증·프라이버시·검증 수준·안티골)을 질문 도구와 일관되게 채우는 구조로 만든다.

## 비목표(제외)

- check-framework 게이트 변경(존재 검사 유지), Preflight의 초안 감지(관찰 후 별도 후보), 기존 적용 프로젝트 Constitution 갱신(bootstrap이 덮어쓰지 않으므로 무영향)

## 대안과 선택 사유 (구현 방식이 여럿 가능한 경우만 작성, 없으면 이 섹션을 지운다)

| 안 | 장점 | 단점 | 선택 여부·사유 |
|---|---|---|---|
| 템플릿만 재편 | 최소 | 질문이 안 물어져 확정란이 비게 됨 | ✗ — 비일관 |
| 템플릿+질문+부트스트랩 정합화 | 확정란-질문 1:1 대응 | 4파일 동시 변경 | ✅ 채택 |

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 헌법 재편 | 공통 규칙 복제 없음·변경 경계 문구 유지·8개 고유 결정 섹션+미확정 추적 존재 |
| AC-02 | 질문 연결 | prepare-project-context에 고위험·규제·프라이버시·안티골 질문 존재 |
| AC-03 | 엄격한 스킵 판정 | 상태=확정+필수 섹션 존재일 때만 스킵 (초안·불완전·상태 이상은 질문 제시) |
| AC-04 | 부트스트랩 정합화 | project-bootstrap 산출물·질문 기준이 새 구성과 일치 |
| AC-05 | 회귀 3케이스 | test-framework-assets에 신규 생성·초안 질문·확정 스킵(+불완전 재질문) 케이스 포함·전체 PASS |
