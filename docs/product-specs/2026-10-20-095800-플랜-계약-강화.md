# Product Spec: 플랜-계약-강화

- 상태: approved
- 유형: 수정
- 생성: 2026-10-20
- 사용자 요청: 플랜 단계 계약에 대안 기록·버그 재현 조건·용어 승격 규칙 추가

## 확인 필요 사항

- 없음 — 사용자가 미리보기·근거 정리를 검토하고 "진행"으로 승인함

## 확정 요구사항

- 복수 구현안이 가능한 작업은 각 안의 장단점과 선택 사유를 기록한다
- 버그 유형 명세는 재현 조건(동일 입력·반복 재현 절차·기대 결과)을 필수로 남긴다
- 그릴링으로 확정한 영구 용어·정책은 project-context.md 반영을 제안한다
- 기존 명세(유형 필드 없음)는 게이트 미적용으로 호환 유지한다

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 계약 3규칙 반영 | standard-plan.md에 대안 기록·재현 조건·용어 승격 액션 존재 |
| AC-02 | 명세 템플릿 확장 | new-product-spec.sh 생성물에 유형 필드·재현 조건 섹션 존재 |
| AC-03 | 버그 게이트 차단 | 재현 조건 없는 버그 명세의 계획이 validate에서 EXIT≠0 |
| AC-04 | 비버그 회귀 없음 | 유형 필드 없는 기존 방식 명세는 기존대로 validate 통과 |
| AC-05 | 재현 조건 전수 검사·재현 불가 분기 | 세 항목 개별 미작성 차단, 재현 불가(사유+대체 판정) 경로 지원 |
