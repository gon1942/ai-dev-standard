# Product Spec: Project Preflight

- 상태: approved
- 생성: 2026-10-19
- 사용자 요청: 개발 요청 전 프로젝트 환경·필수 자산·유효성을 공통 기준으로 검사하고, 안전한 누락 골격 생성 및 PASS/WARNING/BLOCK 판정을 제공한다.

## 확정 요구사항

- 기존 분석·골격 검사·초기화 스크립트를 재사용하는 단일 Preflight 진입점을 제공한다.
- 기술 스택, 패키지 관리자, 검증 신호, 프레임워크 자산, 에이전트 설정을 분석한다.
- 누락 자산은 기존 파일을 덮어쓰지 않는 안전한 생성으로만 복구한다.
- Markdown과 JSON 결과, 후속 단계 진행 가능 여부를 제공한다.
- PASS/WARNING/BLOCK으로 Plan·Coding 진입을 구분하고 모든 도구 어댑터가 같은 엔진을 호출한다.

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 공통 Preflight 엔진 | 대상 프로젝트 분석·검사·판정·구조화 보고서를 제공한다. |
| AC-02 | 안전한 누락 복구 | `--repair`는 누락 골격만 만들고 기존 파일을 덮어쓰지 않는다. |
| AC-03 | 유효성 및 결과 판정 | 설정·JSON·스크립트·활성 검증 상태를 PASS/WARNING/BLOCK으로 구분한다. |
| AC-04 | 도구 중립 연동 | Codex 지침과 OpenCode/Claude 스킬이 동일 엔진·결과 규칙을 사용한다. |
| AC-05 | 실제 시나리오 검증 | 정상, 누락/생성/재검사, 오류, 보호, Node/Python, 반복, BLOCK을 실제 임시 프로젝트에서 확인한다. |

## 범위

- 포함: Preflight 스크립트·문서·도구 어댑터·보고서 형식·시나리오 테스트
- 제외: 특정 외부 프로젝트 변경, 의존성 설치, CI/CD 생성, 기존 사용자 파일 자동 수정
