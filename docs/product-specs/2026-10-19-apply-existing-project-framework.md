# Product Spec: 기존 프로젝트 공통 프레임워크 적용

- 상태: approved
- 생성: 2026-10-19
- 사용자 요청: 기존 프로젝트의 소스·문서·지침을 분석하여, 공통 프레임워크를 안전하게 적용할 수 있도록 개선한다.

## 확정 요구사항

- `docs/framework-manifest.md`가 공통 프레임워크의 필수 자산과 적용 규칙의 SSOT가 된다.
- 에이전트는 기존 프로젝트와 프레임워크를 모두 분석하고, 각 자산을 생성·보존·병합 제안·제외로 분류한다.
- 기존 파일의 의미 있는 변경, 검증 명령 연결, 의존성 변경은 사용자 승인 뒤에만 수행한다.
- 사용자에게 수동 스크립트 실행이나 프레임워크 파일 복사를 요구하지 않는다.

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 프레임워크 적용 매니페스트 존재 | 필수 자산·처리 방식·승인 경계가 문서화된다. |
| AC-02 | 기존 프로젝트 적용 스킬 존재 | OpenCode와 Claude 어댑터가 같은 SSOT 절차를 따른다. |
| AC-03 | 적용 전 분석 보고 가능 | 스크립트가 대상 프로젝트의 적용 분류 보고서를 읽기 전용으로 만든다. |
| AC-04 | 안전 경계 유지 | 기존 파일 덮어쓰기·코드/의존성 변경·자동 정책 변경을 하지 않는다. |

## 범위

- 포함: 매니페스트, 에이전트 어댑터, 읽기 전용 적용 계획 보고서, 기존 온보딩 문서·골격 생성기 정합화
- 제외: 특정 외부 프로젝트에 실제 적용, 기존 프로젝트의 코드·의존성·문서 병합 실행
