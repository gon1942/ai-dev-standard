# Product Spec: 프로젝트 부트스트랩과 최종 수렴 판정

- 상태: approved
- 생성: 2026-10-19
- 사용자 요청: 외부 프로젝트의 유용한 원칙을 자체 구현해, 프로젝트 문맥 문서 품질과 최종 검증 판정을 개선한다.

## 확정 요구사항

- 프레임워크 최초 적용 시 분석으로 알 수 없는 정보만 사용자에게 질문한다.
- 답변과 분석 결과로 프로젝트 문맥·아키텍처·프로젝트 원칙 문서를 작성하는 절차를 제공한다.
- 기존 파일은 덮어쓰지 않고 변경안을 승인 후 반영한다.
- 최종 수렴은 AC, 검증, 리뷰, 완료 기록을 모두 확인한 뒤에만 허용한다.

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 프로젝트 부트스트랩 절차 존재 | 분석·질문·문서화·승인 순서가 도구 중립 문서와 스킬에 있다. |
| AC-02 | 프로젝트 문맥·원칙 문서 골격 존재 | 신규/기존 프로젝트가 실제 사실과 결정 사항을 기록할 위치를 갖는다. |
| AC-03 | 기존 파일 보호 | 기존 문서 변경은 diff·승인 후에만 가능하다고 명시된다. |
| AC-04 | 최종 수렴 게이트 존재 | active 모드, AC PASS, 검증 증거, 리뷰 PASS를 검사한다. |

## 범위

- 포함: 부트스트랩 지침·어댑터·입력 초안 도구, 프로젝트 원칙 템플릿, 수렴 스크립트와 작업 흐름 정합화
- 제외: 외부 GitHub 프로젝트 코드·CLI·MCP/hook 전체 도입, 특정 프로젝트 실제 적용
