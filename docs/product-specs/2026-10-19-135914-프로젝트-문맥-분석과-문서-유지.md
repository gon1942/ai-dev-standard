# Product Spec: 프로젝트 문맥 분석과 문서 유지

- 상태: approved
- 생성: 2026-10-19
- 사용자 요청: 신규 프로젝트는 사용자 질문으로 프로젝트 문맥과 필수 문서를 만들고, 기존 프로젝트는 소스코드·설정·테스트를 분석해 누락 문서를 생성하거나 실제 구조와 어긋난 프로젝트 문서를 갱신하도록 개선해줘

## 확인 필요 사항

- 공통 정책·보안·검증 규칙은 소스 분석 결과만으로 자동 변경하지 않는다.

## 확정 요구사항

- 에이전트는 온보딩 때 프로젝트 소스·설정·테스트를 분석해 재생성 가능한 현황 문서를 만든다.
- 신규 빈 프로젝트에서는 목적·스택·주요 흐름·검증 방식 질문으로 프로젝트 문맥을 확정한다.
- 기존 프로젝트에서는 누락된 구조 문서를 생성하고, 실제 소스와 어긋난 프로젝트 구조 문서의 갱신안을 만든다.
- 소스에서 확인 가능한 프로젝트 사실은 문서화할 수 있지만, 공통 정책·보안·검증 규칙 변경은 개선 후보와 사람 승인이 필요하다.

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 소스 분석 | 언어·패키지·실행 명령·소스/테스트 디렉터리·기존 문서를 분석한 현황을 생성한다 |
| AC-02 | 신규 프로젝트 문맥 | 빈 프로젝트에서 질문해야 할 항목과 생성할 프로젝트 문서가 명시된다 |
| AC-03 | 기존 프로젝트 문서화 | 누락 문서는 생성하고, 기존 구조 문서는 소스 기반 갱신 대상으로 구분한다 |
| AC-04 | 안전 경계 | 공통 정책·보안·검증 규칙은 자동 갱신하지 않는다고 명시된다 |

## 범위

- 포함: 프로젝트 분석 스크립트, 생성 현황 문서, 온보딩·에이전트 지침, 프로젝트 문맥 문서 템플릿.
- 제외: 제품 코드 자동 수정, 의존성 설치, 공통 정책·보안·검증 규칙 자동 변경.
