# Product Spec: 검증-계약-강화

- 상태: approved
- 유형: 수정
- 생성: 2026-10-20
- 사용자 요청: 검증 계약의 실패 처리에 testing-policy 회귀 방침 참조 연결

## 확인 필요 사항

- 없음 — 사용자가 단계 대조·변경 파일 목록을 검토하고 "진행"으로 승인함

## 확정 요구사항

- 검증 FAIL/BLOCKED 시 기존 결함(변경 전에도 실패)과 이번 변경의 결함을 구분해 기록한다
- 구분 절차의 원본은 testing-policy 회귀 방침이며 계약은 참조만 연결한다 (복제 금지)
- 게이트·판정 스키마 변경은 하지 않는다

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 계약 반영 | standard-verify.md Exit에 testing-policy 회귀 방침 참조 존재 |
| AC-02 | 게이트 회귀 없음 | 기존 계획들 validate-plan PASS 유지 |
