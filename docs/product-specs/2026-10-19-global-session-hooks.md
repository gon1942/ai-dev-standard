# Product Spec: Global Session Hooks

- 상태: approved
- 생성: 2026-10-19
- 사용자 요청: AI 에이전트를 시작할 때 Project Preflight를 자동 실행하되, 사용자 작업 요청마다 같은 검사를 반복하지 않는다.

## 확정 요구사항

- Codex, OpenCode, Claude Code의 사용자 전역 시작 지점에서 공통 Session Preflight를 호출할 수 있다.
- 프레임워크가 없는 프로젝트에서는 파일을 생성·수정하지 않고 적용 분석만 제안한다.
- 기존 사용자 설정은 보존하며 hook은 병합하고 반복 설치 시 중복하지 않는다.
- 전역 설정을 수정하기 전 기존 파일을 백업한다.
- hook이 실패하거나 지원되지 않아도 프로젝트 안의 공통 session-preflight 명령은 계속 쓸 수 있다.

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 공통 hook 설치 | 세 도구가 공통 SessionStart 실행 파일을 참조할 수 있다. |
| AC-02 | 안전한 비적용 프로젝트 처리 | 프레임워크가 없으면 대상 프로젝트 파일을 바꾸지 않는다. |
| AC-03 | 설정 보존·반복 안전성 | 기존 hook을 유지하고 동일 항목을 한 번만 추가한다. |
| AC-04 | 설치 결과 문서화 | 신뢰 절차, 재시작, 실패 시 수동 경로를 설명한다. |
