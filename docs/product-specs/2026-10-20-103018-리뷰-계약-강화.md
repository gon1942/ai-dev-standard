# Product Spec: 리뷰-계약-강화

- 상태: approved
- 유형: 수정
- 생성: 2026-10-20
- 사용자 요청: 리뷰 계약에 독립성·Evidence Review 축·WARN 경로 명확화 추가

## 확인 필요 사항

- 없음 — 사용자가 상세 분석을 검토하고 "진행"으로 승인함 (WARN 경로는 권장안 ① 채택)

## 확정 요구사항

- 리뷰는 구현 에이전트와 분리된 관점으로 수행하며 diff와 기록만 근거로 삼는다
- Evidence Review 축: 각 PASS가 실제 실행 증거(명령·종료코드·출력)와 일치하는지 대조한다
- WARN 경로: FAIL은 되돌림, WARN은 사유와 함께 사람 판단 대기(자동 진행 금지)

## 완료 조건 (Acceptance Criteria)

| ID | 완료 조건 | 기대 결과 |
|---|---|---|
| AC-01 | 계약 반영 | standard-review.md에 독립성·Evidence 축·WARN 경로 문구 존재 |
| AC-02 | 체크리스트 반영 | review.sh 출력에 Evidence Review 항목 존재 |
| AC-03 | 게이트 회귀 없음 | 기존 계획 3건 validate-plan PASS 유지 |
| AC-04 | 스크립트 정상 | review.sh 문법 통과·실행 정상 |

## 범위

- 포함: docs/skill-contracts/standard-review.md, scripts/review.sh
- 제외: 어댑터 스킬(자동 전파), converge-plan.sh, reviewer 서브에이전트(기존 독립성 유지), PLACEHOLDER 자동화 연결(후순)
