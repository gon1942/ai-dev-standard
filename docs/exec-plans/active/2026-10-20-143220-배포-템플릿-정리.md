## 구현 계획

- 목적: 프레임워크 개발 원본의 이력과 로컬 상태를 보존하면서, 신규 프로젝트·향후 CLI가 소비할 깨끗한 배포 템플릿을 재현 가능하게 만든다.
- 범위: Bootstrap의 신규 프로젝트 자산 복사 범위 보완, 템플릿 빌드·회귀 테스트 추가, volatile 생성물 ignore 정책, 원본·배포물 경계 문서화.
- 제외: GitHub 원격 저장소·Release·npm CLI 생성, 기존 활성 계획의 완료 이동, 로컬 OpenCode 의존성 물리 삭제, CI/CD·전역 Hook 변경.
- 영향 파일 (예상): `scripts/bootstrap-framework.sh`, `scripts/build-framework-template.sh`, `scripts/test-framework-template.sh`, `scripts/test-framework.sh`, `.gitignore`, `README.md`, `docs/framework-distribution.md`, `templates/project/README.md`.
